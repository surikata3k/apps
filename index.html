Small apps to learn and work, right in your browser.

Password tools, hands-on cryptography and blockchain simulators, and helpers for the classroom. Open one and start: there is no account, nothing to install and nothing you type is sent anywhere.

how they work

Private by design

Every calculation happens in your browser with JavaScript and the Web Crypto API. Nothing is uploaded, logged or stored on a server.

Made for class

They come from teaching systems administration and cybersecurity, so each one explains what it does, with examples and a short FAQ.

Open and reusable

The code is on GitHub under CC BY-NC-SA 4.0: share and adapt it for non-commercial use, with credit.
